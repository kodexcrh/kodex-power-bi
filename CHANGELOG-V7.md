# KODEX V7

- 21 visuales incluidos en un único suite.
- FormattingSettingsService para cargar valores actuales del panel Formato.
- Formato común KODEX: fondo, opacidad, borde, radio, colores, tipografía, sombra y glow.
- Etiquetas: mostrar etiquetas, valores y leyenda.
- Interacción: selección Power BI, hover y animación.
- SelectionManager para puntos categóricos donde aplica.
- Smart Dropdown y Table con render HTML dedicado.
- Geo Map con coordenadas latitud/longitud y burbujas.
- Timeline/Calendar/Heatmap/Sankey con mappings específicos.
- npm workspaces y scripts para typecheck y empaquetado.
